# Markdown Writing & Formatting Guide

Markdown allows you to format text, create headings, lists, tables, links, images, code blocks, equations, quotes, and more.

---




| Purpose | Markdown |
|---------|----------|
| Heading | `# Heading` |
| Sub Heading | `## Sub Heading` |
| Bold | `**text**` |
| Italic | `*text*` |
| Bold + Italic | `***text***` |
| Underline | `<u>text</u>` |
| Strikethrough | `~~text~~` |
| Highlight | `<mark>text</mark>` |
| Inline code | `` `code` `` |
| Code block | ````` ``` ````` |
| Link | `[text](URL)` |
| Image | `![text](image)` |
| Bullet list | `- item` |
| Numbered list | `1. item` |
| Quote | `> quote` |
| Horizontal line | `---` |
| Checkbox | `- [ ] task` |
| Checked box | `- [x] task` |
| Inline equation | `$x^2$` |
| Display equation | `$$x^2$$` |
| Underline | `<u>text</u>` |
| Superscript | `<sup>text</sup>` |
| Subscript | `<sub>text</sub>` |
| Highlight | `<mark>text</mark>` |
